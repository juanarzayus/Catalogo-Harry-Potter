Documentación del Proyecto

Desarrollo y Tecnologías Utilizadas (HTML, CSS y JS)

La aplicación está diseñada bajo una arquitectura de Aplicación de Página Única donde el contenido de las pestañas se carga dinámicamente sin recargar la página:

  • HTML5: Proporciona la estructura semántica base del proyecto, definiendo el contenedor principal #contenedordepaginas y las vistas HTML modulares de cada catálogo.
  • CSS3: Garantiza un diseño adaptativo y moderno usando Flexbox y CSS Grid, con estilos personalizados para cada módulo, efectos hover e identidades visuales únicas.
  • JavaScript (Vanilla JS): Controla toda la interactividad del sistema: gestiona la navegación por pestañas (tabs), realiza solicitudes asíncronas con fetch() y async/await, y construye dinámicamente las tarjetas en el DOM.
